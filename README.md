# EPUB Health Checker

A Python tool for validating EPUB 2 and EPUB 3 files.

## Features

✔ Structure Check

✔ OPF Validation

✔ Metadata Check

✔ HTML Validation

✔ CSS Validation

✔ Image Validation

✔ Font Validation

✔ Link Validation

✔ Navigation Validation

✔ NCX Validation

## Requirements

Python 3.11+

## Install

pip install -r requirements.txt

## Usage

python main.py
