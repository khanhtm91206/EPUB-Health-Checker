Read and verify ZIP entries, including CRC errors, to detect damaged EPUB archives.

🔎

Full Validation

Perform deeper EPUB checks using the available validators.

Get started in minutes

No installer or Python environment needed.

Download

Get the Windows ZIP package from the latest GitHub Release.

Extract and run

Unzip the entire folder, then double-click EPUB_Health_Checker.exe. Keep the _internal folder alongside it.

Scan EPUBs

Choose files or a folder, select a scan mode, and export lists of problematic files if needed.
